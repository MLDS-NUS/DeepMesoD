# Operator audit

For `J`, verify the unit-sum residual and every configured symmetry. Compare its
identifiable action `Jm - m`; do not interpret an unidentifiable center
coefficient.

For `K = B B*`, report the complete constant-force response `[K[m]1]_x`,
conditional covariance calibration, quadratic statistic, state coverage, and
seed variability. Positive semidefiniteness follows from the factorization and is
not calibration evidence.

Free-energy density is defined up to an additive constant. If plots subtract each
curve's minimum, state that convention. Omitting `(beta Vc)^-1 div_m K` changes
the inferred force and must be labeled as an ablation.
