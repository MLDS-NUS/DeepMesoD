# CrBr3 VAMPIRE input files

This directory contains the atomistic simulation inputs used to generate the
CrBr3 training data:

- `input`: VAMPIRE coarsening-dynamics input template;
- `CrBr3.mat`: CrBr3 material parameters;
- `CrBr3.ucf`: the 84-layer honeycomb unit cell with the mid-plane stacking fault.

The raw atomistic trajectories are generated by VAMPIRE from these files. The
resulting spin snapshots are then coarse-grained into the mesoscopic field
stored under the CrBr3 `train_ns` data directories, with three atomic layers
grouped into each of the 28 z slabs.
