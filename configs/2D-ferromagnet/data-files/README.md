# 2D-ferromagnet Vampire input files

This directory contains the atomistic simulation inputs for the
`2D-ferromagnet` experiment:

- `input`: Vampire time-series simulation settings;
- `FM2D.mat`: the single-material ferromagnet parameters.

Vampire generates the atomistic spin trajectories from these files. The
trajectories are then coarse-grained into the 2D vector fields.
